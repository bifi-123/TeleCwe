Przestępność:
Limit pamięci: 32 MB
Mamy dany rok 1 <= r <= 8000. Powiemy, że rok r jest przestępny, gdy wartość r jest podzielna przez 4. Jeśli jednak wartość r dzieli się przez 100, a nie dzieli się przez 400 to rok r nie jest przestępny. Zadaniem Twojego programu jest stwierdzenie czy dany rok jest przestępny.

Zadanie:
Napisz program, który:

wczyta ze standardowego wejścia liczbę naturalną r oznaczającą rok,
wypisze TAK jeśli rok r jest przestępny, albo NIE jeśli nie jest.

Wejście:
Jedna liczba naturalna 1 <= r <= 8000 oznaczającą rok.

Wyjście:
W jedynym wierszu wyjścia należy wypisać TAK jeśli rok r jest przestępny, albo NIE jeśli nie jest.

Przykład
Dla danych wejściowych:

1066

poprawną odpowiedzią jest:

NIE
